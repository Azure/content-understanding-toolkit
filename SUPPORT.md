# Support

This support policy applies to all current and future tools in the Azure
Content Understanding Toolkit. A tool may provide additional guidance in its
own directory.

## Toolkit bugs and feature requests

Use [GitHub Issues](https://github.com/Azure/content-understanding-toolkit/issues)
to report reproducible toolkit bugs or request toolkit features. Search existing
issues before opening a new one, and identify the affected tool in the title
and description. GitHub issue response times are not guaranteed.

Do not report security vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) to report them privately.

## Usage help

Start with the README and support documentation for the affected tool. For
example:

- [CU CLI documentation](cu-cli/README.md)
- [CU CLI support guidance](cu-cli/SUPPORT.md)
- [Azure Content Understanding documentation](https://aka.ms/cu-doc)

## Azure service support

This repository's issue tracker supports the open-source toolkit; it is not an
Azure support channel. For Azure service incidents, account or subscription
issues, quota requests, billing issues, or problems requiring an assured
response, use an
[Azure support plan](https://azure.microsoft.com/support/options/) to
[create an Azure support request](https://azure.microsoft.com/support/create-ticket/).

## Microsoft Support Policy

Support for the open-source tools in this repository is limited to the
resources listed above unless a tool explicitly states otherwise. Experimental
tools and features are provided without a service-level agreement.
