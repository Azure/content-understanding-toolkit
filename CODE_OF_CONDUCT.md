# Microsoft Open Source Code of Conduct

This project has adopted the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
The code of conduct applies to all current and future tools, project spaces,
and community interactions associated with the Azure Content Understanding
Toolkit.
