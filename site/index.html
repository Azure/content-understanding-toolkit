Microsoft Azure AI Content Understanding

The toolkit for building on Content Understanding.

Content Understanding turns documents, images, audio, and video into structured output. These are the tools that make it faster to adopt — a command line, the prebuilt schemas, and field-tested practices for putting the results into production.

What's in the toolkit

Four tools, one service.

Start with the command line to get content flowing, use the schema index to pick the right prebuilt analyzer, then decide what a human still needs to check.

Command line Preview

CU CLI

A standalone cu command for analyzing files, creating and testing custom analyzers, managing resource profiles and model defaults, and generating the Azure infrastructure to run on. Takes local files, HTTPS URLs, or blob SAS URLs.

python -m pip install cu-cli

Get content flowing in three commands.

You need Python 3.10 or later and the Azure CLI for sign-in. Point the CLI at a file and it returns structured output you can pipe straight into whatever comes next.

1 · Install python -m pip install cu-cli
2 · Point at your resource cu profile set endpoint https://<resource>.services.ai.azure.com/
3 · Analyze cu analyze ./invoice.pdf
