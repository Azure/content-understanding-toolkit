# Contributing to the Azure Content Understanding Toolkit

Thank you for your interest in contributing. This repository welcomes
contributions and suggestions for all current and future tools in the Azure
Content Understanding Toolkit.

## Contributor License Agreement

Most contributions require you to agree to a Contributor License Agreement
(CLA) declaring that you have the right to, and actually do, grant us the
rights to use your contribution. For details, visit
<https://cla.opensource.microsoft.com>.

When you submit a pull request, a CLA bot automatically determines whether you
need to provide a CLA and decorates the pull request with the appropriate
status check and instructions. Follow the instructions provided by the bot.
You need to complete this process only once across repositories that use the
Microsoft CLA.

This project has adopted the
[Microsoft Open Source Code of Conduct](CODE_OF_CONDUCT.md).

## Before contributing

1. Search [existing issues](https://github.com/Azure/content-understanding-toolkit/issues)
   and pull requests to avoid duplicate work.
2. Open an issue before making a substantial change so maintainers can confirm
   scope and direction.
3. Read the contribution guide in the tool directory you plan to change. Each
   tool owns its development setup, test commands, and additional requirements.

For example, see the [CU CLI contribution guide](cu-cli/CONTRIBUTING.md).

## Pull requests

- Keep each change focused and explain its user impact.
- Add or update tests and documentation when behavior changes.
- Run the checks documented by the affected tool.
- Do not include credentials, customer data, confidential information, or
  generated artifacts that the tool does not explicitly track.
- Link the related issue in the pull request description.
