# Content Understanding Toolkit

This repository contains supporting reference material for Azure AI Content Understanding.

## Prebuilt schema definitions

The [`prebuilt-schema/`](prebuilt-schema/README.md) directory documents the field schemas returned by Azure Content Understanding's domain-specific prebuilt document analyzers, organized by document family and API version. Use [`prebuilt-schema/SUPPORTED_ANALYZERS.md`](prebuilt-schema/SUPPORTED_ANALYZERS.md) for a single-file lookup of every domain-specific analyzer ID and description by API version, or [`prebuilt-schema/README.md`](prebuilt-schema/README.md) for category-oriented navigation and custom analyzer guidance.
