# Content Understanding Toolkit

This repository contains supporting reference material for Azure AI Content Understanding.

## Prebuilt schema definitions

The [`prebuilt-schema/`](prebuilt-schema/README.md) directory documents the field schemas returned by Azure Content Understanding's prebuilt document analyzers, organized by document family and API version. Start at [`prebuilt-schema/README.md`](prebuilt-schema/README.md) for a categorized index of every analyzer, including the analyzer ID to use when calling the API.
